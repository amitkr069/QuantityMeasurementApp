# QuantityMeasurementApp

## Use Case 1


### Features

Length conversion (km, m, cm)

Weight conversion (ton, kg, g)

Temperature conversion (C, F, K)

Volume conversion (L, mL, gallon)

Conversion history support


### Tech Stack

JavaScript

JSON Server


### Setup

Install Node.js

Install JSON Server:

npm install json-server

Start server:

npx json-server --watch db.json --port 3000

Open project in browser


### API Endpoints

/units

/conversions

/history
